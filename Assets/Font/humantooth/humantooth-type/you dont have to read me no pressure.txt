Thanks for downloading my first font!

My first introduction to typography was the Bone Thugs-n-Harmony logo. As a young girl, I would endlessly try to perfect drawing it, cracking the code so I could make more letters using the same rules. My introduction to hand styles was the cholo letters I would see everywhere growing up in San Ysidro (a stones throw from the Tijuana border), which I think inadvertently seeped in to this font the further I went. 

If you want to see other projects I've made and ways I've abused text, check out my website at https://humantooth.neocities.org (not mobile-friendly!)

HumanTooth was built pixel-by-pixel, using BitFontMaker 2 from https://pentacom.jp 

Free for any kind of use! If you feel like sharing, I'd love to learn what you did with it! Shoot me an email at humantooth@protonmail.com

Enjoy!
